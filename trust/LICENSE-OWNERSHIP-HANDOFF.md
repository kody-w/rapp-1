# License and ownership decision handoff

**Status: human decision required. No license grant is made by this document.**

The Protocol Constitution records an intent to permit implementation, but the
repository currently has no owner-ratified root `LICENSE`. Contributor or licensor
authority asserted for this work does not supply the missing legal text, ownership
record, or estate-owner signature.

Before adding a root license, Kody/Wildhaven should decide and record:

| Decision | Required owner answer |
|---|---|
| Licensor identity | Exact legal person or entity granting rights |
| Covered material | Whether protocol text, reference code, schemas, tests, books, artwork, and generated artifacts share one grant or use separate grants |
| Incoming contributions | DCO, CLA, assignment, or another provenance policy |
| Existing contributions | Evidence that the chosen licensor can license each covered contribution |
| Patent terms | Whether an express patent grant is required |
| Trademarks | Which RAPP/Wildhaven names and marks remain outside the copyright license |
| Third-party material | Inventory and treatment of notices already present under `book/assets/` |
| Effective act | Exact owner-ratified commit or signed decision that makes the grant operative |

Acceptance criteria for the human handoff:

1. Counsel or the authorized licensor supplies the exact license text and scope.
2. The owner confirms contribution provenance and any exceptions.
3. The license is introduced in its own reviewable change with the owner-ratified
   evidence identified.
4. Documentation claims are updated only after that grant is actually effective.

This trust-registry proposal does not depend on a guessed license and must not be
used as evidence that a root grant already exists.
